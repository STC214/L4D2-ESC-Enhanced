# L4D2Evolved：小地图位置与尺寸设置

> 本文是 Evolved 1.2.5 的位置/尺寸研究，不是 C 的内置功能或当前安装清单。检查日期的文件存在性与静态实现不能当作所有版本的实机验收；C 的网络图位置也不是本页的小地图位置。

记录日期：2026-10-26。适用对象为本项目保存且与检查时游戏目录逐字节匹配的 **Evolved 1.2.5 x86** 核心 DLL。

## 结论与验证范围

- 支持通过配置自定义小地图位置和尺寸，位置使用两个空格分隔的浮点比例值。
- 位置与尺寸按游戏渲染区域计算，不是 Windows 桌面坐标，也不是窗口外框坐标。
- 已检查配置解析、位置与显示尺寸换算，以及鼠标交互相关代码；尚未启动游戏验证具体操作和视觉效果。
- 代码存在拖动位置、记录变更并调用配置更新回调的分支；触发拖动所需的交互状态尚待实测，暂不把“按 F8 后直接拖动”写成确定操作。
- 本次记录没有修改游戏配置、插件或 MOD。

## 1. 实际配置文件

```text
E:\SteamLibrary\steamapps\common\Left 4 Dead 2\Evolved\config.txt
```

检查时，该文件和游戏中的 `bin/neko/plugins/L4D2Evolved.dll` 均存在；`Evolved/config2.txt` 不存在。这是本次观察到的状态，不根据之前的安装或清理记录推断当前状态。

配置中的现有值：

```ini
NoHmdMinimapWidth=0
NoHmdMinimapHeight=0
NoHmdMinimapPosition=
NoHmdMinimapSize=0.210937634 0.236111075
```

| 配置键 | 作用与使用说明 |
|---|---|
| `NoHmdMinimapPosition` | 小地图横向、纵向位置比例；空值使用插件默认位置 |
| `NoHmdMinimapSize` | 小地图宽度、高度的比例设置；通常优先调整这一项 |
| `NoHmdMinimapWidth` | 备用宽度设置；目前保留 0，不与比例尺寸同时调整 |
| `NoHmdMinimapHeight` | 备用高度设置；目前保留 0，不与比例尺寸同时调整 |
| `NoHmdMinimapEnabled` | 小地图开关，与位置设置是不同功能 |
| `NoHmdWorldNavigationEnabled` | 实景导航箭头开关，不由小地图位置值控制 |

`config.sample` 中以 `#` 开头的行是样例注释。实际生效设置应写入 `config.txt`，对应行前面不加 `#`。

## 2. 位置格式与坐标方向

```ini
NoHmdMinimapPosition=X Y
```

- `X` 从渲染区域左侧向右计算。
- `Y` 从渲染区域顶部向下计算。
- 使用小数点与空格，例如 `0.02 0.03`；不要使用逗号或直接填写 `1280 720`。
- `0.1` 表示该方向屏幕尺寸的 10%，不是 0.1 像素。
- 代码会检查数值并限制位置；实际窗口还受边缘、最小尺寸和内部布局约束。

基础换算：

```text
横向位置 ≈ 渲染宽度 × X
纵向位置 ≈ 渲染高度 × Y
```

例如 `0.02 0.03` 在 1280×720 下，位置约为距左 25.6 像素、距上 21.6 像素；实际显示可能因取整和边界限制略有调整。

## 4. 尺寸调整与屏幕适配

```ini
NoHmdMinimapSize=宽度比例 高度比例
```

当前比例在 1280×720 下换算约为 **270×170 像素**，在 1920×1080 下约为 **405×255 像素**。这些是比例换算值，最终可见范围还受插件最小尺寸、边框和内部布局影响。

例如，尝试较小尺寸：

```ini
NoHmdMinimapSize=0.18 0.20
```

在 1280×720 下换算约为 230.4×144 像素。通常无需同时修改 `NoHmdMinimapWidth` 和 `NoHmdMinimapHeight`。

为预留边距，可参考：

```text
X + 宽度比例 < 1
Y + 高度比例 < 1
```

这只是避免越界的基础估算，不替代游戏内验证。改变尺寸后应重新检查位置；不同宽高比下，相同比例也未必保持相同的像素形状或 HUD 相对关系。

## 5. 修改步骤

1. 完全退出游戏，先备份当前 `config.txt`。
2. 找到已有的 `NoHmdMinimapPosition` 与 `NoHmdMinimapSize`，局部修改，不重复追加同名键。
3. 保存文件，再启动游戏并进入地图检查。
4. 先只改位置，确认无遮挡后再调整尺寸，便于定位问题。
5. 更换分辨率、窗口模式或地图后，再检查位置和布局。

文本修改后的运行时热重载机制尚未验证，因此本教程采用退出游戏后修改、重新启动读取的方式。若未来出现 `config2.txt`，应先核对当前版本的读取/覆盖规则，不直接假定其优先级或把同一设置写入多个文件。

## 6. 恢复检查前的设置
