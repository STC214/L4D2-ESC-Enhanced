# C＋数字喷漆便携整合包

适用于 **v1.15.0／Spray Studio 1.12.0**。下载 `L4D2_Tools_Portable_v1.15.0.zip`，完整解压到可写目录，保留目录结构；不要在 ZIP 内直接运行。

## 包内有什么

| 入口／目录 | 用途 |
|---|---|
| `Deploy.cmd` | 同时部署 C＋原始 40 槽数字喷漆选择器 |
| `Spray_Manager.cmd` | 打开喷漆工具，导入和管理个人素材 |
| `manager/` | 原生 EXE、喷漆说明和主题示意图；首次启动在旁边创建 `CSP_Spray_Data` |
| `game/` | C VPK／DLL、数字喷漆 VPK／选择器 DLL、80 份配套散装 VTF／VMT，共 84 个资源文件 |
| `diagnostics/` | 独立诊断编号包与自制编号联系图，不随整包入口自动安装 |
| `docs/`、`evidence/` | 项目说明、版本记录和构建验收证据 |
| `manifest.json` | ZIP 内文件的 SHA256 清单 |

这是当前全部功能成品的整合，不包含源码开发环境、L4N 平台、TUMTaRA 地图本体或任何个人喷漆素材；L4N 和地图依赖需自行提前安装。

## 一键部署 C＋原始数字喷漆

1. 完全退出游戏及同目录的喷漆管理器。确认已有配套 x86 L4N，存在 `bin/neko/source_nekomimi.exe`，MOD 首条搜索路径为 `update`。
2. 双击 `Deploy.cmd`。首次选择**包含 `left4dead2.exe` 的游戏根目录**，不是其下的 `left4dead2` 子目录。目录保存在 `manager/CSP_Spray_Data/settings.json`；以后可使用上次目录或选择更换。
3. 工具检查整包所有待装组件的固定哈希、数字底板字节、游戏目录及原生文件保护项，显示游戏绝对路径和变更文件数。
4. 确认后备份并部署 **C 和原始数字喷漆**，启用两个项目的 addonlist 条目，停用诊断编号包条目，保留其他 MOD 的字节。
5. 完成后重启游戏，在**进入战役前**选择喷漆。手工改名的旧 C、旧测试包及其他覆盖同一路径的 MOD 仍需自行检查冲突。

**注意：这个入口会用数字喷漆覆盖游戏中本项目的同名自定义喷漆。** 原游戏文件先备份，可回退；工具保存的个人槽位、源图和母版不会被重置。如果只想部署自己的素材，请用 `Spray_Manager.cmd` 打开工具并点击其中的“一键部署到游戏…”；该按钮只部署当前喷漆，不重新安装 C。

底板固定来自项目原始数字版 `CSP_Numbered_Selector_TEST.vpk`，SHA256：

```text
27cd1dbfdba0e9fbdb02c0340a3fc6fe89298315a1a6edc0020248868f37ec70
```

打包不从游戏目录或生产工具数据目录取喷漆；数字 VPK、80 份散装资源均逐字节核对。C VPK、C DLL 和选择器 DLL 也固定版本哈希，损坏或被替换会停止部署。

## 回退、清理和升级

- 需要撤销时，打开**同一便携目录**的 `Spray_Manager.cmd`，选择同一游戏路径，点击“回退最近操作”。同一次整包部署中的 C、喷漆、addonlist 一起精确恢复；首次新增的文件会被移除。
- 恢复记录位于 `manager/CSP_Spray_Data/managed-transactions/`。中断后保留检查点；先回退再尝试新操作。备份或目标被外部改动时会拦截，不盲目覆盖。
- 回退指向最近一次游戏操作。整包部署后再次部署个人喷漆或执行清理，会更新“最近操作”；不要把它理解为任意版本历史选择器。
- “清理游戏内本项目产物…”仅清理固定 C＋喷漆清单，不删除 L4N、其他 MOD 或工具的个人素材。
- 升级前关闭工具，保留整个 `manager/CSP_Spray_Data`。不要把新便携包解压到游戏目录；新包的 `game/` 是供部署程序读取的资源目录。
- 程序整个目录被自行删除时，配置和恢复记录也会丢失。已有自定义喷漆用户不要反复运行整包数字底板入口。

详细喷漆操作见包内 `manager/使用说明.md` 或项目的“喷漆工具使用说明”；C 的使用和冲突说明见包内 `docs/C使用说明.md`。

## 验证边界

自动验收使用模拟游戏目录，覆盖完整 84 文件安装、addonlist、精确回退、重复安装、损坏包和确认期间改动；不对真实游戏执行整包安装。开发期间不查看用户喷漆画面。未知游戏二进制的运行兼容性、真实游戏效果和完整人工点击仍待试用。
