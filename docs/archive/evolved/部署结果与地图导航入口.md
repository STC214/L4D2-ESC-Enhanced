## 不用地图快捷键也能开关

已在原生设置描述表及设置渲染代码中找到：

- 「小地图导航」→ `NoHmdMinimapEnabled`。
- 「实景导航箭头」→ `NoHmdWorldNavigationEnabled`。

因此保留已有路径，不重复增加一个控制同一设置的菜单：

1. 打开 Evolved 设置（当前总设置键为 F8），在设置列表中用鼠标操作上述两个开关。
2. 也可在游戏控制台输入 `evo_config`，打开同一设置菜单，再操作两个开关。该命令不是模拟按键：已追踪到命令注册、对象回调和设置窗口标志写入。
3. 退出游戏后，也可直接修改 `Evolved/config.txt` 的上述两项，再启动。运行时热重载机制未验证，不承诺编辑文本后立即刷新。

这里说“不用地图快捷键”，是无需按 Ctrl+M 才能开启地图/导航；F8 或控制台命令是进入已有设置界面的方式。没有新增 C 的 ESC 按钮或 L4N 菜单项。

静态入口证据在 `menu_route_evidence.json`：描述表项位于 `0x103fee90` / `0x103feee0`，设置列表渲染函数 `0x10107490`，设置行渲染函数 `0x10105d00`。`evo_config` 对象位于 `0x105a4c4c`，回调 `0x100ed2f0` 将设置窗口标志置为 1。地址属于这个精确哈希的原始 DLL，不能套用于别的版本。
