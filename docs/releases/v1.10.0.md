# v1.10.0 预发布：1024 母版与清晰度优先导入

Spray Studio **1.8.0**；C、选择器 UI 和 DLL 不变。

## 新的转换策略

按用户确认的“清晰度优先、保留动画”策略，替换旧版 RGBA 动画为满足容量而自动降至 64／128 的路径：

- 普通静态图片以 **1024×1024** 方形母版处理，原比例居中、透明留白；游戏贴图为 **1020×1024 DXT1**，单帧单 mip，共 **522320 字节**。不是严格的 1024×1024 游戏贴图，以给文件头留出容量。
- GIF／APNG 先按原画布合成，再保存每个保留帧的 **1024×1024** 母版；游戏贴图固定 **512×512 DXT1**，最多保留连续前 **3 帧**，不跳帧、不降为 64。三帧共 **393296 字节**；超过三帧会明确报告舍弃数量，少于三帧不补帧。单帧 GIF／APNG 按静态尺寸导出。
- 使用内置 Go DXT1 编码器，无外部压缩工具或 DLL 依赖。按每个 4×4 块的颜色端点压缩，编码为有损 RGB565／**1 位透明**：alpha <128 为透明，其余为不透明。半透明渐变在游戏贴图中会量化，母版保留 8 位透明度；不称为无损或原画质。
- 每个导出帧的母版存入私有导入批次：首帧沿用 `preview.png`，后续为 `master_002.png`／`master_003.png`，路径写入槽位清单。母版不进入游戏 VPK 或部署清单，不把母版尺寸冒充游戏输出尺寸。
- 导入结果和点击槽位后的状态显示母版尺寸、实际游戏尺寸、DXT1／透明度取舍、原始／保留帧数与最终字节。批次弹窗仅展开前三项，其余查看对应槽位。
- VTF／VPK 内现成贴图继续按原字节保留，不放大、不重新压缩。小尺寸输入放大到母版不会凭空增加细节。GIF／APNG 仍使用保留前缀帧的平均速率并循环。

## 升级与旧素材

关闭程序，替换 `CSP_Spray_Manager_v1.8.0.zip` 中 EXE，保留整个 `CSP_Spray_Data`。**旧版已经降分辨率的素材需要重新导入原图／原动图，再构建并退出游戏后部署。仅重新构建不会恢复已丢失的细节。** 原文件和旧批次不删除。

完整附件 `L4D2_ESC_All_Products_v1.10.0.zip`；首次安装选择器附件 `CSP_Selector_Complete_v1.10.0.zip`。本轮不自动覆盖真实游戏素材；已有自定义素材勿被基础编号包覆盖。

## 验证与边界

84 项 Go 顶层测试双轮，新增 DXT1 颜色／透明块及非四倍尺寸、静态／动画母版落盘、实际分辨率与精确字节预算、合成／前缀帧／材质构建、不向 VPK 打包母版等回归。另做乱序复核、原生动画局部绘制及部署／精确回退。

开发验证仅使用自制图形，不查看用户喷漆画面；用户 VPK 只检查结构、元数据、引用及字节不变。真实游戏的有损压缩观感、透明边缘和动画效果仍待用户试用。
