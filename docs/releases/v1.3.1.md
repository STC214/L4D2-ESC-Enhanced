# C 1.3.1：勾选提交、延迟确认与二值项前置

## 本次修复

- 10 项二值设置使用真正的勾选框，勾选/取消即调用原生 `ApplyChanges`。显式选择匹配本机 ABI 的 GameUI 控件工厂，并限定在 `C_ESC_BOOL_` 名称及对应参数的白名单内。
- 二值项集中前置，两个分组各自保留原相对顺序，导航同步更新，连续数值仍保留滑条。
- 最终审查发现“地图全亮”在后续渲染帧才更新，即时读回产生误报。改为 PENDING→延迟确认，不再过早 Reset；超时不重试、不锁值、不保留已关闭的 UI 指针。支持取消尚未落地的开请求，原生绘制刷新不代替用户提交。
- 修复窗口回调测试的 PID 复用旧日志假阳性，增加四个有效槽位隔离、异步提交及失效指针测试。
- 发布器切换 1.3.1，并增加审查后源码变动、DLL 哈希、旧 helper 版本和成品漂移拦截。更新安装与回退教程，避免使用历史三文件事务回退当前菜单版本。

## 安装

推荐下载 `C_session_release.zip`，完全退出游戏后解压到包含 `left4dead2.exe` 的游戏根目录，**同时更新 VPK 与 DLL 1.3.1**，保留现有 L4N。

- 固定 VPK 名称：`【00】C_ESC_LED_血条和速度_TUMTaRA.vpk`
- DLL：`bin/neko/plugins/CSessionDefaults.dll`
- [使用说明](../C使用说明.md)／[勾选与提交细节](../C勾选与提交.md)

天气/尸体 0、手电光圈 165、光亮度 1、光射程 3000、轮廓禁用参数 0 的一次性默认项保持不变。手电贴图/shader、聊天及 HUD 资源不变。相对两档过渡版本，VPK 只有 ESC 菜单一个成员变化，另升级配套 DLL。

## 验证与边界

发布要求两轮完整审查通过且 VPK/DLL/ZIP 哈希一致：48 项整包回归、13＋7 项部署事务测试、5 项发布守卫测试、原生 x86/真实 DLL/窗口回调、2832 个 shader 程序反汇编、补丁重放和成套回滚副本。

用户已实测勾选功能恢复；最新实机日志记录了字幕、提示、雾等提交成功。最终追加的延迟确认修正有受控回归测试，仍需新一轮实际日志确认，不将静态测试写成实机全覆盖。本版保留预发布标记；服务器仍可能覆盖轮廓等变量，组件不移除标志或持续强制。

本机证据：`reports/c_current_review/verification.json`、`reports/c_checkbox_bridge/verification.json`、`reports/c_session_deploy/verification.json`。
