# v1.15.0 预发布：C＋数字喷漆一键便携包

Spray Studio **1.12.0**；C **1.3.2／DLL 1.3.1**、选择器 **UI 0.2.4／DLL 0.2.3** 保持原版本。

- 新整合附件：`L4D2_Tools_Portable_v1.15.0.zip`。完整解压后双击 `Deploy.cmd`，已有 L4N 的前提下同时安装 C 和原始 40 槽数字喷漆。
- 包含全部当前成品资源、喷漆 EXE、配套选择器 DLL、80 份散装资源、说明和诊断附件。L4N、地图本体、个人素材不包含。
- 喷漆底板固定为原始数字版 VPK，SHA256 `27cd1dbfdba0e9fbdb02c0340a3fc6fe89298315a1a6edc0020248868f37ec70`，不是游戏内已部署版本。打包和部署均检查固定哈希及散装资源字节。
- 新整包入口预检并弹窗确认目录和数量，备份后写入；覆盖游戏内同名自定义喷漆前明确提醒，保留工具内个人槽位。可在同一便携目录的喷漆工具中“回退最近操作”。
- 原喷漆工具按钮仍只构建并部署当前个人喷漆；整包部署通过独立入口调用，避免日常喷漆更新重装 C。
- 本机生产 EXE 维护路径更新为 `D:\tools\01_Game_tools\L4D2_tools\spray_importer_go`。
- 113 项 Go 顶层测试双轮，9 项打包测试；模拟目录验证整包安装、精确回退、重复安装、损坏组件和确认竞态，原生 UI／目录窗口及 C 回归保持。

详细步骤见 [便携整合包使用说明](https://github.com/STC214/L4D2-ESC-Enhanced/blob/v1.15.0/docs/便携整合包使用说明.md)。

旧版本和附件不覆盖。本轮生产部署仅更新工具 EXE，不在真实游戏执行整包安装；用户素材未预览，真实游戏效果与完整人工点击仍待试用。
