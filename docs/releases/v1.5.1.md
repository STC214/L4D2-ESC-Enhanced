# v1.5.1 预发布：Spray Studio 1.2.1 审查修复

C 保持 **1.3.2／DLL 1.3.1**，独立选择器保持 **0.2.3**。本次只更新原生工具和构建／发布保护，不改游戏默认值或喷漆刷新机制；保留旧 v1.5.0 Release。

## 修复

- 素材列表增加明确的键盘焦点描边，尊重系统隐藏焦点提示状态；后台任务结束后恢复本窗口原控件焦点。
- 原生 Go 校验器直接读取候选 EXE 的资源树，逐一匹配当前 ICO 的 7 张 PNG，阻止旧 COFF 对象与新 ICO 混用。
- 先构建候选 EXE，通过测试、图标核对、渲染、原生窗口及源码快照检查后，才原子替换正式成品。校验失败不会先覆盖已知可用的成品。
- 保存替换前副本并读回核验。修复 PowerShell 5 对 File.Replace 空备份参数的兼容问题，使用明确备份路径。
- 构建前后锁定源码快照，避免用后来修改的源码哈希替尚未重建的 EXE 背书。

## 下载与升级

推荐工具包 **`CSP_Spray_Manager_v1.2.1.zip`**。关闭旧工具，只替换 EXE，保留同目录 `CSP_Spray_Data`；本次无须重装 C 或重新导入素材。

全新安装可下载 **`L4D2_ESC_All_Products_v1.5.1.zip`**：game 内文件复制到含 left4dead2.exe 的游戏根目录，manager 为工具；需要已有 x86 L4N。单独选择器包为 `CSP_Selector_Complete_v1.5.1.zip`，其 update 中的 80 个素材仍是必需项。

另外提供原有 `C_session_release.zip`、单独 C VPK、工具 EXE、自制编号诊断 VPK／总览图和 `SHA256SUMS.txt`，共 9 个附件。诊断 VPK 不与完整选择器同时启用。原图、用户素材、工具数据、真实备份和历史故障版本均不打包。

## 验证边界

37 项 Go 测试连续两轮通过，无跳过，新增链接图标一致／不一致／截断 PE 回归及列表焦点提示检查。另有 3 项 PowerShell 文件事务测试：损坏候选、锁定目标不会替换原文件，正常替换与精确备份通过。原生窗口、实际焦点绘制、图标加载与源码快照核对通过；C 完成两轮完整静态／原生／恢复测试，产物不变。

发布前核对 ZIP CRC／成员哈希，公开前后逐项核对远端 SHA-256／大小和标签提交。完整人工点击、目录对话框、其他 DPI／系统主题及服务器兼容仍待更多试用；有限测试不代表永久无缺陷。Go vet 保留必要的 Win32 原生指针边界例外。

外观沿用 v1.5.0 的深色卡片、青绿按钮和用户指定内置图标。文档中的预览仍为离屏 GDI 渲染，不冒充桌面截图。游戏内仍应在进入战役前选择喷漆，局内更换不立即刷新。
