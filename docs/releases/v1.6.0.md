# v1.6.0 预发布：VPK 直接导入与全帧保留

本次更新 **Spray Studio 1.4.1**。C 保持 **1.3.2／DLL 1.3.1**，独立选择器保持 **0.2.3**，不改变游戏刷新机制。

## 喷漆工具

- 一次选择 1～2 个完整单文件喷漆 VPK，识别包内喷漆 VTF／VMT 引用，与已有素材合并后自然排序、连续编号 01～40。两个包内同名资源分别保留；同一来源重复导入更新原记录。
- VPK 的静态／动画 VTF 原样保留所有帧和 mipmap，不抽取首帧、不缩放、不解码画面。界面仅显示结构参数，旧版 VPK 来源记录同样不生成画面预览。
- 结构校验覆盖帧数、编码、尺寸、各 mip／帧字节范围；本轮补齐旧布局长度一致性及资源表缩略图偏移、重叠和标志检查。
- 原样 VTF 小于 512 KiB，支持二维 VTF 7.0～7.5、1～256 帧及 RGBA/BGRA/RGB/BGR/DXT1/3/5。动画数据完整保留不等于游戏自动播放已验收；不注入额外动画代理。
- 坏包、缺失引用、坏贴图或合并超过 40 槽时整批停止。原始 VPK 不修改；导入后仍需重新构建、退出游戏后部署。
- 发布校验区分顶层测试、子测试与 fuzz 种子，要求每个顶层测试完整通过两轮。生产部署支持原 EXE 备份、重复部署幂等、安装哈希／PE 核验及 EXE 回退，保留整个 `CSP_Spray_Data`。

## 下载与升级

工具包：**`CSP_Spray_Manager_v1.4.1.zip`**，或单独 `CSP_Spray_Manager.exe`。关闭旧工具，仅替换 EXE，保留同目录 `CSP_Spray_Data`。无需重装 C；要重新导入原 VPK 并构建，才能用原样资源替换旧版已转换素材。

全套：**`L4D2_ESC_All_Products_v1.6.0.zip`**；游戏文件在 game，工具在 manager。单独选择器包为 **`CSP_Selector_Complete_v1.6.0.zip`**，update 内 80 个配套素材仍须安装。需要已有 x86 L4N，发布包不包含完整平台。诊断 VPK 不与完整选择器同时启用。

另提供原有 C 安装 ZIP、C VPK、自制编号诊断 VPK／总览图及 SHA256SUMS，共 9 个附件。用户素材、原图、工具数据、生产备份及本机私有验收记录不打包。

## 验证与边界

61 项 Go 顶层测试连续两轮通过；另做乱序复核、限时 VTF 元数据模糊测试、发布脚本测试、双包 30 张素材的纯结构／字节一致性验收、81 文件模拟部署和精确回退，以及生产 EXE 替换／回退隔离测试。用户素材未解码、未查看、未渲染；真实游戏未自动部署新素材。

原生窗口冒烟、内置图标、源码快照和成品哈希一致性核验通过。`go vet` 保留既有 Win32 LPARAM 原生指针边界例外。完整人工文件对话框、游戏内播放、不同 DPI／服务器组合仍待试用。重复有限审查未发现新增问题，不作永久无缺陷保证。游戏内仍在进入战役前选择喷漆，局内切换不立即刷新。
