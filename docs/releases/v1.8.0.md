# v1.8.0 预发布：正方形等比例动画预览与图片点击选择

Spray Studio **1.6.0**，选择器 UI **0.2.4**；桥接 DLL 保持 0.2.3，C 保持 1.3.2／DLL 1.3.1。

- EXE 预览保持原来的正方形范围，静态／动态素材等比例居中，透明空白显示预览区域背景色，不再显示棋盘格。
- 游戏内每个编号的缩略图区为正方形，确认预览也为正方形；按 VTF 元数据尺寸计算图片显示矩形，不拉伸原图，不改动原始 VTF 帧或 mip。
- 缩略图本身增加透明点击层，点击图片与点击编号进入同一确认界面；确认后应用，取消不更改，原有键盘导航保留。
- 构建同时更新游戏内 UI 与实际喷绘材质的 AnimatedTexture 代理，二者引用同一份多帧 VTF、使用同一播放速率。单文件、文件夹、VPK 及 GIF 导入均验证保留动画，静态素材不加动画代理。
- VTF 原字节保留，默认 10 FPS；GIF 保留全部帧，仍按平均延时转换为统一速率并按容量预算调整输出分辨率。没有新增 APNG/WebP 支持；识别到 APNG 会明确提示先转换为动画 GIF／VTF，单文件和目录导入均停止，不静默截取默认帧。

## 升级

关闭工具，替换 `CSP_Spray_Manager_v1.6.0.zip` 中 EXE，**保留 CSP_Spray_Data**。已有导入记录直接重新构建，退出游戏后由工具部署，便可带上新的游戏内预览布局／材质；旧构建包不会自动获得新功能。

首次安装使用 `CSP_Selector_Complete_v1.8.0.zip`，需要已有 x86 L4N 及配套 update 素材。已有自定义喷漆时不要用基础包覆盖素材，使用工具重新构建部署。全套附件为 `L4D2_ESC_All_Products_v1.8.0.zip`，不包含完整 L4N。

仍应在进入战役前选择，局内重新选择不立即刷新。服务器规则及引擎限制仍然适用。

## 验证边界

71 项 Go 顶层测试双轮、选择器双轮静态／原生夹具检查、EXE 原生动画定时器冒烟，以及部署／精确回退隔离检查。新增覆盖横图／竖图、透明背景、多种导入路径保帧、UI 与世界材质代理、40 个编号的布局与点击命令。

开发期间只用自制色块进行像素测试。用户两个 VPK 仅检查结构、材质引用、帧数及字节／哈希，不查看或解码画面。真实游戏的动画渲染、鼠标点击及不同分辨率仍待人工试用；静态契约通过不等于游戏内实测通过。
