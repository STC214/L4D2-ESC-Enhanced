# v1.11.0 预发布：槽位编号命名与一键恢复默认

Spray Studio **1.9.0**；C、选择器 UI 和 DLL 不变。

- 单文件、目录、双 VPK 导入后，全部已导入槽位统一显示为“喷漆 01”～“喷漆 40”，工具管理的贴图副本为 `test_001.vtf` 等；预览和母版副本同样带槽位号。原始输入文件不改名、不删除。
- 保留原文件名用于自然排序和来源识别；批次重排后重新编号，不把新的数字显示名用于文件名排序。旧清单在下一次成功导入时升级。
- 新增“恢复全部默认槽位…”按钮，确认后一次清空 40 槽自定义绑定，回到内置默认素材。保存恢复前后清单到数据目录 `resets/<批次>/`，保留原图、母版、历史批次和游戏回退备份；不是磁盘空间清理功能。
- 重复恢复默认无副作用；损坏的旧素材也可清除绑定后重新导入。外部清单变化或未完成的部署事务会拦截操作。恢复后的旧构建失效，须重新构建。
- **恢复不直接修改游戏文件。需要游戏内也恢复时：恢复全部默认 → 构建 → 退出游戏 → 部署。** 若要换一批素材，恢复后导入新素材，再构建部署即可。
- 静态／动画预览、原比例透明留白、1024 母版、静态 1020×1024 DXT1、动画 512×512 连续前最多三帧策略不变；现成 VTF／VPK 仍字节不变。

升级：关闭工具，替换 `CSP_Spray_Manager_v1.9.0.zip` 中 EXE，保留整个 `CSP_Spray_Data`。全套为 `L4D2_ESC_All_Products_v1.11.0.zip`，首次安装选择器为 `CSP_Selector_Complete_v1.11.0.zip`；勿用基础素材覆盖已有自定义素材。

验证：89 项 Go 顶层测试双轮，另有乱序复核、8 按钮原生窗口与动画局部绘制检查、默认包成员精确相等、假游戏部署与回退、生产 EXE 替换与回退。开发只使用自制颜色素材；用户 VPK 仅结构／哈希／字节检查，不查看画面。真实游戏渲染及完整人工点击仍待用户试用。
