# C 1.2.3：手电光圈随地图初始化

- `r_flashlightfov` 默认 **165**，在每关进入可游玩状态时，使用与天气、尸体数量相同的本地变量设置及读回路径，执行一次。
- 移除首次 ESC 设置 150 和键盘监听逻辑。连接 CFG 同步为 165，避免排队执行 CFG 时覆盖为旧值 53。
- 光圈菜单范围保持 **50～200**，步进 1；手动调节后不锁定、不随 ESC 重置。下一关、重载地图或重新连接时重新初始化。
- 保留天气、尸体默认 0，光亮度 1、光射程 3000，以及全屏约 91% 不透明背景和现有聊天布局。

## 成品与部署

- `dist/【00】C_ESC_LED_血条和速度_TUMTaRA.vpk`
- `dist/c_session_helper/CSessionDefaults.dll`（1.2.3）
- `dist/C_session_release.zip`：包含上述两件套，按游戏目录相对路径解压安装；需要现有 L4N 加载器。

```text
python -X utf8 tools/build_c_session_plugin.py
python -X utf8 tools/build_c_mod.py --width 1280 --height 720
python -X utf8 tools/verify_fov165.py
python -X utf8 tools/review_c_session_deployment.py --deploy
```

部署前退出游戏。安装位置分别为游戏目录下 `left4dead2/addons/` 与 `bin/neko/plugins/`，不要同时启用多份 C。

自动化测试覆盖本地命名设置及读回、无需 ESC 的进图初始化、手动光圈 80 连续 100 次轮询保持、下一关重设 165、加载/背景地图/录像排除，以及实际 DLL 的窗口定时回调。VPK 只改动连接 CFG 和光圈控件注释，其他资源保持上一版内容。

- 针对性记录：`reports/fov165/verification.json`
