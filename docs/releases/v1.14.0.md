# v1.14.0 预发布：一键部署、游戏内项目清理与可恢复事务

Spray Studio **1.11.0**；C **1.3.2／DLL 1.3.1**、选择器 UI **0.2.4／DLL 0.2.3** 不变。

## 一键部署到游戏

- 自动构建当前槽位；首次使用且没有导入时生成默认 40 槽。
- 首次安装／更新喷漆选择器 VPK、80 份散装贴图材质、内置且固定哈希的 `CSPSelector.dll`，并启用 addonlist 对应条目。只安装喷漆，不安装 C 或 L4N。
- 仍需提前安装配套 L4N，当前检查 `bin/neko/source_nekomimi.exe` 布局，首条 MOD 搜索路径为 `update`。选择器原生桥接仍以已支持的 x86 游戏版本为前提，不自动适配未知引擎。
- 诊断编号资源包仅停用启用条目，避免与正式选择器同时加载；其他 MOD 的 addonlist 字节保留。

## 清理游戏内本项目产物

用户确认的范围是 **C＋喷漆组件**，不是清空工具缓存：

- 固定 85 个可能存在的项目文件：C VPK／辅助 DLL、喷漆选择器 VPK／DLL、40 个 VTF 和 40 个 VMT、诊断编号 VPK。
- 仅移除三个项目 VPK 的 addonlist 条目；支持 UTF-8／BOM 及既有 CP936 项目名，不重编码其他内容。重复项、坏结构和不支持的编码会停止预检。
- 先生成本地 `preflight/cleanup-plan.json` 列出全部绝对路径，再弹窗确认。游戏运行时拦截；不使用通配符，不递归删除目录。
- 不删除其他 MOD、L4N、游戏原生文件、`config.cfg`、用户原图或工具数据。手工改名副本不做模糊匹配。

## 备份、回退和复核修复

- 一键安装和清理使用独立恢复事务，保存原件是否存在、原始字节、哈希及完成状态。新旧部署入口统一选择最新恢复记录。
- “回退最近操作”既能恢复清理，也能移除首次安装新增的文件；不会清空本地导入槽位。
- 处理前再次检查确认期间的外部改动，未完成事务阻止新操作；中断后保留恢复入口。回退过程中每个文件写入前也重新核对，发现外部改写则停止并保留检查点，冲突解除后可继续。
- 首次部署进度不提前跳到 100%；回退也按处理量显示进度。
- 发布校验将 EXE 内置选择器 DLL、构建记录哈希与独立选择器附件 DLL 绑定核对，避免不同桥接版本混装。

## 获取与升级

- 独立工具：`CSP_Spray_Manager_v1.11.0.zip` 或单独 EXE。
- 全部成品：`L4D2_ESC_All_Products_v1.14.0.zip`。
- 手动安装选择器附件：`CSP_Selector_Complete_v1.14.0.zip`，不含完整 L4N。

关闭旧工具，替换 EXE，保留整个 `CSP_Spray_Data`。清理后的“一键部署”只恢复喷漆；恢复 C 请回退清理或按 C 的安装说明操作。目标文件、addonlist、原生文件或备份被外部改动时，恢复会拦截，不覆盖外部改动。

详细步骤见 [喷漆工具使用说明](https://github.com/STC214/L4D2-ESC-Enhanced/blob/v1.14.0/docs/喷漆工具使用说明.md)。

## 验证与边界

110 项 Go 顶层测试双轮、10 按钮原生窗口／进度／动画／配置保存检查、乱序首装／清理／精确回退／中断与竞态回归、7 项打包规则测试，以及 C 两轮完整回归与九个发布附件哈希校验。

开发验证仅使用自制图形、模拟游戏目录；用户 VPK 仅元数据／CRC／字节一致性检查，不查看画面。生产维护只替换工具 EXE 并验证回退，不对真实游戏执行一键安装或清理。真实游戏运行效果和完整人工点击仍待试用；末轮未发现新增问题不是永久无缺陷保证。
