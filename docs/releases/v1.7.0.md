# v1.7.0 预发布：恢复预览并补齐动画喷漆

工具更新为 **Spray Studio 1.5.0**。纠正 1.4.x 将开发约束误做成产品限制的问题：**成品显示静态预览，并循环播放动画；开发期间仍不查看用户素材画面。** C 1.3.2／DLL 1.3.1、选择器 0.2.3 保持不变。

## 功能与文案

- VPK 静态喷漆恢复预览，动画 VTF 逐帧循环；旧导入记录直接兼容。预览不修改源贴图或额外落地 PNG。
- 单张和目录导入支持动画 VTF、静态／动画 GIF；VPK 提取、自然排序、40 槽位、备份／回退保持原有行为。选择器、确认框、状态栏与说明同步标明静态／动画支持。
- VTF 保留全部原始帧与 mip；预览按正确帧／mip 布局解码。动画槽位构建 AnimatedTexture 材质代理，VTF 默认预览和材质速率均为 10 FPS。
- GIF 支持透明局部帧及 background／previous disposal 合成，保留全部帧，自动选 16～256 方形输出尺寸以满足 VTF 小于 512 KiB。各帧延时按平均值转成统一 1～100 FPS 并循环播放；零延时按 0.1 秒处理，不保留不等长延时和有限循环次数。
- GIF 上限：输入 32 MiB、256 帧、画布 8M 像素、累计画布／帧区域 64M 像素。VTF 上限：二维 7.0～7.5、256 帧、原文件小于 512 KiB、既有 RGBA/BGRA/RGB/BGR/DXT1/3/5 编码。超限不丢帧，整批停止。
- 生产升级归档上一次部署记录和备份，重复安装不覆盖恢复入口，保留整个数据目录。

## 升级

关闭旧工具，使用 **CSP_Spray_Manager_v1.5.0.zip** 或单独 EXE 替换程序，保留 `CSP_Spray_Data`。旧 VTF 记录可直接预览；要生成动画代理，重新构建并退出游戏后部署。游戏内仍应在进入战役前选择喷漆，局内切换不立即刷新。

全套为 `L4D2_ESC_All_Products_v1.7.0.zip`，独立选择器包为 `CSP_Selector_Complete_v1.7.0.zip`。update 的 80 个配套素材仍是必需项，需要已有 x86 L4N。旧版本附件不覆盖。用户原图、原始喷漆包、数据目录和生产备份不打包。

## 验证边界

67 项 Go 顶层测试两轮通过；新增七种编码的双帧 mip 定位、GIF 延时和 disposal 合成、限制／篡改检查、材质代理及旧记录预览测试。原生 Win32 冒烟实际触发动画定时器并切换自制颜色帧。成品哈希、图标、源快照、部署／回退和 ZIP 成员哈希均核对。

**只用程序生成的测试图验证画面。** 对用户两个 VPK 的检查仅涉及结构、引用及字节／哈希，未调用其预览或像素解码；不自动部署真实游戏素材。实际游戏播放、完整人工选择对话框和不同服务器／DPI 仍待试用，不把代码测试等同于全部实机验收。
