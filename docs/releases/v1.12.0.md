# v1.12.0 预发布：动画导入进度、最低帧数和单份备份

Spray Studio **1.10.0**；C、选择器 UI 和 DLL 不变。

## 动画导入

- 新增原生进度条：GIF／APNG 的读取、完整结构校验、帧合成、DXT1 压缩和保存分阶段更新。APNG 读取及压缩阶段按实际处理量更新；不靠计时器虚增进度，耗时的 GIF 解码阶段可能暂时停在同一位置。目录导入按素材数量汇总，后台处理不阻塞窗口，失败不会显示成功完成。
- 窗口右上新增“动画最低帧数（2～256）”，默认 **30**；在开始导入时校验并保存到数据目录 `settings.json`，下次打开保留设置。
- 先按现有清晰度和容量策略计算可保留连续前缀帧数。**少于阈值时，只取正确合成的第一帧作为静态喷漆**，游戏贴图为 1020×1024 DXT1，保留 1024 母版；不会用隐藏默认图替代动画第一帧。达到阈值才保留动画，等于阈值也保留；原始素材始终不变。
- **当前 512×512 DXT1 动画预算最多保留 3 帧，因此默认 30 会将 GIF／APNG 转为首帧静态。希望保留当前前缀动画时设为 2 或 3。** 设置阈值不会降低分辨率来凑帧数，也不是提高容量上限。转换结果报告可保留帧数、阈值和静态回退原因。
- 以上只适用于图片转换。现成 VTF／VPK 仍按字节原样导入，包含动画的 VTF 不因该阈值而被重编码或截帧。静态／动画预览及等比例显示继续保留。

## 只保留最新一份备份

- 每次成功导入或恢复默认后，仅保留最新一套 `before.json`／`after.json` 清单备份；旧清单快照删除，已引用的贴图、预览、母版、原文件、批次历史和游戏部署事务恢复记录不删除。
- 启动时以当前清单和完整快照核对后清理历史快照；无有效替代备份或存在待恢复事务时保留旧记录。清理失败不伪称导入失败，显示维护警告并保留可用新备份。
- 生产维护脚本在成功 Verify 后只保留最新可用 EXE 回退备份，清理 `.release-backups` 中被替代的 EXE；待完成事务不清理，回退状态不清理。路径限制、链接检查和新备份哈希验证全部先于删除，绝不递归删除数据目录。
- 此策略不是删除全部历史素材来释放空间。游戏文件恢复入口仍是“回退最近部署”。

升级：关闭工具，替换 `CSP_Spray_Manager_v1.10.0.zip` 中 EXE，保留 `CSP_Spray_Data`。完整附件 `L4D2_ESC_All_Products_v1.12.0.zip`；首次安装选择器用 `CSP_Selector_Complete_v1.12.0.zip`。换图后构建并退出游戏后部署；已有低清素材仍需重新导入原图。
