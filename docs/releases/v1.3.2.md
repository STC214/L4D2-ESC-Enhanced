# C 1.3.2：原生 ESC 菜单置顶与手电光圈默认值 114

## 更新

- 最左列原生菜单置顶：返回游戏、闲置、投票、邀请好友、排行榜、统计与成就、第三方附件、音频、选项、退出到主菜单。
- 其后依次排列：分屏模式、踢出玩家、电视亮度说明、字幕说明、游戏提示说明。
- 本轮只修改 ESC 资源中 15 项的纵向位置；保留原有上下导航环，其余 222 个资源和 DLL 不变。
- 相对公开版 1.3.1，另包含此前已部署的手电光圈默认值 165 → 114：每次进入地图初始化一次，不锁定手动调整，反复 ESC 不重置。
- 修正审查工具对旧光圈默认值的断言；精确验证 CFG 的这一处变化，不放宽其他资源校验。

## 安装

退出游戏，备份现有文件，将 `C_session_release.zip` 解压到含 `left4dead2.exe` 的游戏根目录，保留现有 L4N 加载器。

```text
left4dead2/addons/【00】C_ESC_LED_血条和速度_TUMTaRA.vpk
bin/neko/plugins/CSessionDefaults.dll
```

**整包版本为 1.3.2，配套 DLL 内部版本仍为 1.3.1。** DLL 与光圈 114 部署版本完全相同；不是把 DLL 版本号改成 1.3.2。建议使用完整 ZIP，独立 VPK 不包含默认项和勾选提交组件。

[完整使用说明](../C使用说明.md)

## 验证及边界

发布前要求连续两轮全量静态／回归审查通过，并验证 VPK、DLL、ZIP 构建结果一致。包含 50 项整包测试、13＋7 项部署事务测试、7 项发布守卫测试、原生 DLL／窗口回调、shader 检查、补丁重放及回退副本。

相对本次排序前版本：唯一变化成员为 `resource/ui/l4d360ui/ingamemainmenu.res`，且只有 15 项顶层 `ypos` 变化；光圈 114、天气／尸体默认值、HUD、手电材质和勾选提交逻辑均保持不变。

本机游戏目录已部署并校验一致；菜单实际渲染、各游戏模式下按钮显隐及交互仍需实机验收。因此继续标记为预发布，不承诺自动化覆盖所有游戏内行为。

本机证据：`reports/c_current_review/verification.json`、`reports/esc_left_order/verification.json`、`reports/c_session_deploy/verification.json`。这些报告不作为下载附件分发。
