# v1.9.0 预发布：动画局部刷新、现代目录窗口与 APNG

Spray Studio **1.7.0**；选择器 UI 0.2.4／DLL 0.2.3、C 1.3.2／DLL 1.3.1 不变。

## 本轮修复与功能

- 动画帧更新仅使预览矩形失效，不请求擦除背景；局部绘制直接覆盖完整帧，不在帧前重绘窗口场景，避免由整窗重绘及先清背景造成的闪动。其他窗口重绘和尺寸变化仍正常处理。
- “导入目录”采用系统 IFileOpenDialog 文件夹模式，提供资源管理器式地址栏、导航与文件夹选择；限定文件系统目录，不改工作目录、不写最近使用记录。取消不导入，不回退到旧目录树窗口。
- 支持 `.apng` 以及含 APNG 动画块的 `.png`，单文件／目录导入均可。处理隐藏默认图、局部帧、SOURCE／OVER 混合、NONE／BACKGROUND／PREVIOUS 处置和透明度，初始画布为透明。
- APNG 输出 RGBA VTF：先从 256 调整至 128／64 方形画布，等比例透明留白；在 64 档仍超过严格小于 512 KiB 的上限时，仅保留连续前缀帧，最多 31 帧。未超限则保留全部帧，绝不抽样跳帧。结果弹窗和槽位记录说明原始／保留／舍弃帧数、输出尺寸与字节数。
- APNG 播放使用保留帧平均延时换算的统一 1～100 FPS，并循环；不保留不等长帧延时、有限播放次数、色彩管理及额外 PNG 元数据。源文件不变。
- 输入上限 32 MiB，画布边长 8192、8M 像素，最多 10000 个声明帧；保留帧累计画布最多 64M 像素。先检查全部块范围、CRC、序号和帧数，再解码保留帧；损坏／超处理预算时停止导入，不提交半批。容量截断后的舍弃帧不解码像素，仅检查结构和 CRC。WebP 尚未支持。

## 升级与使用

关闭旧程序，替换 `CSP_Spray_Manager_v1.7.0.zip` 中 EXE，保留整个 `CSP_Spray_Data`。已有素材和导入记录继续使用。导入或更新素材后，重新构建，退出游戏再部署。游戏内仍应在进入战役前选择，局内切换不立即刷新。

首次安装可用 `CSP_Selector_Complete_v1.9.0.zip`，全套为 `L4D2_ESC_All_Products_v1.9.0.zip`；已有自定义素材不要被基础编号包覆盖。需要既有 x86 L4N，发布包不包含完整平台。

## 验证与边界

76 项 Go 顶层测试双轮通过，新增覆盖 APNG 合成／截帧／损坏拒绝、导入构建和持久化通知、真实 COM 对话框创建／选项及 Win32 局部失效矩形。原生窗口冒烟额外要求动画实际走预览局部绘制分支。另做乱序复核、生产替换／精确回退和发布附件一致性核验。

不查看或解码用户原始喷漆画面；像素验证使用自制色块，原 VPK 仅结构／帧数／引用／字节验收。系统对话框人工选择、不同 DPI／显卡的闪烁观感、真实游戏动画与点击仍待试用。本轮最后复核未发现新增问题，不作永久无缺陷保证。
