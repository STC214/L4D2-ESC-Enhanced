# C 1.3.0：轮廓默认项、原生开关与手电着色器整合

> **旧版发布记录。** 1.3.0 的勾选提交缺陷由 1.3.1 修复，当前安装见 [教程](../C使用说明.md)。本文的三文件迁移回退不是当前菜单更新的常规回退入口；共享生成目录也不保证仍保留本版文件。

## 本次变化

- 每次进入可游玩地图，尝试将角色与远处物品的禁用轮廓参数设为 0。与天气系统共用一次性初始化，手动修改不因反复 ESC 重置，下关/重载重新初始化。
- 10 个真正的二值设置改用游戏原生 `CvarToggleCheckButton`；连续数值保持滑条。两个轮廓项标为“关闭角色轮廓”“关闭远处物品轮廓”，默认不勾选，勾选后的效果与文字一致。
- 集成普通 DXT5 手电贴图（顶层 RGB 均值约 190.00）及已实测的抑制末端淡出、RGB 2 倍着色器，新增一个 shader 成员，C 共 223 个成员。无额外纹理采样；不承诺屏幕亮度恰好翻倍或完全没有任何形式的衰减。
- 保留天气/尸体 0、手电光圈 165、光亮度 1、光射程 3000，以及既有聊天、HUD、TUMTaRA 和菜单背景。
- 本机整合部署同时备份 C、DLL 和旧独立测试包；只停用哈希与测试记录匹配的独立包，防止同一 shader 被重复覆盖。失败自动恢复三者。

## 安装与回退

见 [使用说明](../C使用说明.md)。推荐安装 `C_session_release.zip` 中的 VPK 与 DLL 1.3.0，保留现有 L4N。独立 `C_flashlight_nofade_TEST.vpk` 不再需要。

本机部署及完整三文件回退入口：

```text
python -X utf8 tools/deploy_c_integrated.py deploy
python -X utf8 tools/deploy_c_integrated.py verify
python -X utf8 tools/deploy_c_integrated.py rollback-preview
python -X utf8 tools/deploy_c_integrated.py rollback
```

回退依赖本机事务备份；手动下载 ZIP 的用户使用自己的成套备份。
