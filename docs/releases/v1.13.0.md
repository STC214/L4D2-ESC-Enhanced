# v1.13.0 预发布：游戏路径记忆、配置保护与目录整理

Spray Studio **1.10.1**；C **1.3.2／DLL 1.3.1**、选择器 UI **0.2.4／DLL 0.2.3** 不变。

## 游戏目录自动保存

- 首次填写有效游戏根目录后，停止输入约 0.8 秒、离开输入框或正常关闭窗口时自动尝试保存；部署／回退前同样检查。下次启动自动恢复，通常只需设置一次。
- 保存到 EXE 旁的 `CSP_Spray_Data/settings.json`，与动画最低帧数共存，不写注册表。保留整个数据目录升级或移动即可保留配置；删除整个程序目录后不保证恢复。
- 新目录检查 `left4dead2.exe` 与 `left4dead2/gameinfo.txt` 的文件元数据；错误、未完成的输入和写入失败不覆盖上次有效路径。不执行游戏文件，不打开用户喷漆画面。
- 已记住路径暂时离线时保留配置，不自动清空。运行中单独删除配置文件会重建已记住的值；配置被外部修改或损坏时提示处理，不用旧内存值覆盖它。动画最低帧数保存采用同样的冲突保护。

## 整理与说明

- 配置逻辑独立为 `native/spray_importer/settings.go`，与转换策略／清单保留逻辑分开。
- 当前教程统一为 [喷漆工具详细使用说明](../喷漆工具使用说明.md)，独立工具 ZIP 的 `使用说明.md` 直接采用该教程，并修正独立 ZIP 内的历史文档链接。
- 旧喷漆实现长文档归档到 `docs/archive/spray_importer/`；原文档地址保留导航页，修复归档后相对链接。新增 [项目目录说明](../项目目录说明.md)。
- 构建基线、私有素材、生产数据和真实游戏素材不作批量搬移或删除。已发布附件保持不变，本轮使用新标签和新附件。

## 既有行为

动画最低帧数仍为 2～256、默认 30；512×512 DXT1 转换预算最多 3 帧，默认转首帧静态，设为 2 或 3 可保留前缀动画。原样 VTF／VPK 不受该阈值影响。1024 母版、槽位编号、一键默认恢复、动画局部预览及最新可用备份策略不变。
