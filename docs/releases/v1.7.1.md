# v1.7.1 预发布：动画合成与部署恢复审查修复

工具更新为 **Spray Studio 1.5.1**。保留静态／动画预览、GIF／VTF 动画导入和动画材质构建。C 1.3.2／DLL 1.3.1、选择器 0.2.3 保持不变。

## 本轮修复

- GIF 首帧仅覆盖部分逻辑画布时，按其逻辑背景初始化，避免把不透明背景错误合成为透明。透明 GIF、局部帧和 background／previous disposal 回归保持通过。
- 部署核验不再将 PREPARED 记录视为已完成安装；未知状态、错目标记录均停止，不覆盖恢复记录。通过构造未完成状态，在旧版复现错误返回成功后修复。
- 部署日志改为独占临时文件写入、刷新落盘、JSON／字节读回、原子替换，并保留替换前记录；临时文件操作后清理。日志与历史路径拒绝重解析点。
- 同一会话内按生产目录加命名互斥锁，拦截并发安装／核验／回退，避免恢复记录互相覆盖；旧记录和备份保留。
- 原始 VPK、既有素材和整个 `CSP_Spray_Data` 不修改。部署只替换 EXE，并保留原版本备份；重复安装仍保持幂等。

## 下载与升级

关闭工具，使用 `CSP_Spray_Manager_v1.5.1.zip` 或单独 EXE 替换程序，保留数据目录。全套为 `L4D2_ESC_All_Products_v1.7.1.zip`；选择器为 `CSP_Selector_Complete_v1.7.1.zip`，已有正常安装者无需为本次 EXE 修复重装 C 或选择器。

仍须先构建、退出游戏后部署；进入战役前选择喷漆，局内切换不立即刷新。需要既有 x86 L4N，不随包提供完整平台。旧版附件不覆盖，用户素材、生产备份和私有测试记录不打包。

## 验证边界

68 项 Go 顶层测试双轮通过，另做乱序双轮复核、限时元数据模糊测试、动画原生定时器冒烟，以及部署未完成／未知状态拒绝、日志备份／临时文件清理、安装幂等和精确回退测试。相关旧行为先复现，再进行回归。

画面测试仅使用自制色块；用户两个 VPK 仅检查结构、引用和字节／哈希，未调用其像素解码或预览，未自动部署真实游戏素材。实际游戏播放、人工对话框和不同服务器／DPI 仍待试用。最后复核未发现新增问题，不作永久无缺陷保证。
