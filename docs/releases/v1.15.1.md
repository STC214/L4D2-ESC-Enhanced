# v1.15.1 正式发布：仅一个完整便携 ZIP

本次 Release **只上传 `L4D2_Tools_Portable_v1.15.1.zip` 一个成品附件**，不再分别上传喷漆 EXE、各组件 ZIP、C VPK、诊断 VPK、联系图或外部校验文件。GitHub 自动生成的 Source code 下载链接属于平台功能，不是额外成品附件。

截图中各部分的实际资源已经合并到同一 ZIP 的 `game/`、`manager/`、`diagnostics/`、`docs/` 中，不是把多个组件 ZIP 再套一层 ZIP。校验清单 `SHA256SUMS.txt` 和 `manifest.json` 一并放在包内。

- 完整解压后，`Deploy.cmd` 一键部署 C＋原始 40 槽数字喷漆，`Spray_Manager.cmd` 打开个人素材工具。
- 保持 Spray Studio **1.12.0**、C **1.3.2／DLL 1.3.1**、选择器 **UI 0.2.4／DLL 0.2.3**，EXE 和资源字节不变。本轮仅调整打包、发布附件策略和说明，不重新构建 EXE，不改生产目录或真实游戏。
- 原始数字喷漆 VPK 固定 SHA256 `27cd1dbfdba0e9fbdb02c0340a3fc6fe89298315a1a6edc0020248868f37ec70`，不从游戏中已部署的喷漆或个人素材目录取底板。
- 84 份待部署资源、配套 DLL、诊断编号包、联系图和说明全部保留；不包含 L4N、地图本体、个人喷漆素材及本地配置／备份。
- 发布为正式版并设置 Latest。旧版本附件保留在历史 Release，不删除或覆盖。

本轮验证单 ZIP 输出、禁止嵌套组件 ZIP、资源逐字节一致性、内部校验清单、远端唯一附件及 SHA256；打包规则 11 项测试通过，C 完整回归两轮。沿用已经通过 113 项 Go 顶层测试双轮与原生窗口检查的同一 EXE。未查看用户喷漆画面，真实游戏效果和完整人工点击边界不变。
