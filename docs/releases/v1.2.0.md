# C v1.2.0：天气／尸体默认项修复与聊天对齐

## 下载与安装

**推荐下载 `C_session_release.zip`**，退出游戏后按包内目录结构解压到游戏根目录，安装 C VPK 与 **CSessionDefaults.dll 1.2.0** 两件套。需要已有 L4N 插件加载器。

仅更新 VPK 会更新菜单和聊天布局，但不会修复旧版默认项组件的启动问题。独立 VPK 继续使用固定文件名：`【00】C_ESC_LED_血条和速度_TUMTaRA.vpk`。请勿同时启用旧 C、原 A/B 或重复覆盖同一菜单/HUD 的版本。

GitHub 会规范化中文附件名，因此独立下载附件名为 `C_ESC_LED_Health_Speed_TUMTaRA.vpk`，安装前请重命名为上述固定中文文件名；`SHA256SUMS.txt` 也按该安装名记录。**推荐直接使用安装 ZIP，包内已经保留正确中文文件名及配套 DLL，无需手动改名。**

## 本次变化

- 聊天区域中心对齐速度图形表右边缘与武器栏左边缘之间的空白区；输入框底边对齐本玩家血条边框底边。未移动速度表、武器栏或血条。
- 修正初始化过早的问题：等待实际游戏窗口和引擎接口就绪，再从游戏窗口线程应用默认项。
- 雨、雪、雾及客户端尸体数量 0 按地图初始化；加入逐项读回日志。不持续锁定用户之后的设置，不修改变量标记或服务器复制设置。
- 保留首次 ESC 手电光圈 150、后续手动调整不锁定，以及现有菜单、LED、血条、速度和 TUMTaRA 功能。

## 兼容与验证边界

此版作为**预发布版**发布。已完成构建、原生状态/变量接口夹具、真实 x86 DLL 导出加载、资源语法、布局模型、打包 CRC/哈希与部署读回校验；**修复后的游戏内效果仍待重启进图确认**。

组件仅接受本轮核验的 x86 引擎、客户端和 vstdlib 文件版本；不匹配时记录停用原因，不猜测 ABI。默认小地图之外，其他 HUD 或特殊地图粒子可能仍需单独检查。

启动并进图后查看游戏根目录 `CSessionDefaults.log` 中的 `WAIT_WINDOW`、`TIMER_ACTIVE`、`ENGINE_READY`、`CVAR_READY` 和 `DEFAULT_VERIFIED`。需要看到天气与尸体项的实际读回值为 0，才能判定自动默认项在游戏中已生效。

随附 `SHA256SUMS.txt` 校验文件；发布附件以 GitHub 返回的 SHA-256 再次核验。
