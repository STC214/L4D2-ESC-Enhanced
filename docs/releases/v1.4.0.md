## 完整包安装

1. 退出游戏，备份已有同路径文件与 addonlist.txt，准备正常工作的 **x86 L4N**。本发布不包含 L4N 平台、TUMTaRA 地图或其他平台安装器。
2. 将完整包 **game 目录里面的内容**复制到含 left4dead2.exe 的游戏根目录，而不是把 game 目录本身复制进去。
3. 确认 `left4dead2/addons/CSP_Numbered_Selector_TEST.vpk` 启用；已有 addonlist.txt 若把该项设为 0，应改为 1，保留其他附件条目。不要同时启用诊断素材 VPK。
4. C 安装说明和来源冲突见随包 `docs/C使用说明.md`；不要混装旧 C 或单独旧手电测试包。
5. 管理工具在 manager 目录；运行后，单张可指定槽位，整目录导入会递归读取支持的图片，与已有记录合并后按自然文件名排序。
6. 导入后点击构建，退出游戏后部署；重新启动游戏，在进入战役前使用 **选项 → 多人游戏 → CSP TEST** 选择对应编号。

只下载选择器包时，它的 bin、left4dead2、update 三个目录同样复制到游戏根目录。**update 中的 80 个素材不是可省略项**：只装 VPK/DLL 可能出现预览正常但实际喷出旧图片。

更新时关闭游戏和管理工具，保留 EXE 同目录的 `CSP_Spray_Data`。若要卸载或退回发布前状态，恢复安装前备份；工具中的“回退最近部署”只恢复工具最近一次图片部署，不是整个安装包的卸载器。

## 本次修复与验证

- Go 工具完成 29 项测试连续两轮，无跳过；原生窗口、40 槽位、6 个操作按钮、GDI 预览和后台消息回传检查通过。
- 修复同一来源占用多个手动槽位时的非确定更新：固定选择原编号最小的一项，其他重复项保留。额外回归重复执行 16 次。
- 修复目录合并的超限／坏图整批提交保护、清单漂移、未完成事务恢复入口、GIF 预检及 NTFS 重解析路径检查等问题，具体覆盖见工具说明。
- Go 构建支持仓库自带、哈希固定的内置选择器基线，不再强制依赖本地 dist 中存在副本。其他 C／原生分析构建仍依赖各自固定原件、SDK 或本机游戏，不能把原始依赖缺失解释为可无条件跨版本重建。
- C 和选择器分别执行两轮静态／原生／回退测试，检查确定性及游戏文件未变化；发布 ZIP 重开检查 CRC、成员清单和哈希，远端发布后核对每个附件的 SHA-256 和大小。

## 明确边界

用户已确认进入战役前选择新喷漆有效；局内更换不会立即刷新。完整人工文件／目录选择及任意真实图片的观感仍待更多试用，不把自动测试写成全面实机验收。

现有桥接只支持已核对的游戏二进制／ABI，未知版本会停用。原生窗口按系统 DPI 缩放，建议至少 920×650 逻辑像素工作区。Go vet 保留必要的 LPARAM → MINMAXINFO 原生边界例外，其余分析器通过。目录排序不是中文拼音排序；超过 40 张不会静默截断。1.0.1 以前的旧导入记录缺少来源路径，升级不会猜测删除它们。

本发布不新增 Evolved/Skeeto 平台安装器、小地图、自适应网络图高度或局内即时更换喷漆功能；C 本体也没有因此获得这些功能。
