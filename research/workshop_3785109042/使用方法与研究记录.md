## 它是什么

这不是放进 addons 就能完整启用的普通 VPK。它是一套 Windows x86 原生插件增强，页面介绍的功能包括第一人称身体、机瞄 ADS、第三人称瞄准修正、同槽模型切换、部件/材质管理、游戏内模组管理、舞蹈、渲染/帧生成和缓存处理。

实际包中的关键文件：

| 路径 | 静态观察/用途边界 |
|---|---|
| `winmm.dll`、`bin/winmm.dll` | 两份逐字节相同的 x86 DLL；结合安装布局，推断用于启动加载。未跟踪真实加载调用链 |
| `bin/neko/plugins/L4D2Evolved.dll` | x86 核心插件，包含 Evolved 配置、管理器和更新相关字符串 |
| `bin/neko/plugins/L4d2evomodel.dll` | x86 模型功能插件 |
| `Evolved/config.sample` | 配置参考，不是已经生效的玩家配置 |
| `Evolved/d3d9.dll` | 渲染相关组件；保留原目录，不凭名称把它挪到游戏根目录 |
| `Evolved/version.txt`、`manifest.json`、`updatelog.txt` | 三者均表明当前为 1.2.5；更新日志包含中文 |
| `left4dead2/addons/*.vpk` | 两个配套资源包，命中图标与动画资源 |
| `left4dead2/sound/vrmod/*.wav` | 命中、击杀、爆头声音 |
| `删除evo[放游戏根目录使用].bat` | 卸载脚本，已阅读，未执行 |

## 正确安装方式（尚未代为安装）

1. 退出游戏，先备份目标位置已有的同名文件，尤其是根目录和 `bin` 下的 `winmm.dll`。若其他插件也提供同名加载器，先核对它们的安装方式，不直接相互覆盖。
2. 按作者说明，把 **`unpacked/` 内的内容** 按原结构复制到含 `left4dead2.exe` 的游戏根目录，例如 `Steam/steamapps/common/Left 4 Dead 2/`。不是复制到 `left4dead2/addons/`，也不是把整个 `unpacked` 文件夹套在外面。
3. 目录应形成 `游戏根目录/bin/neko/plugins/...`、`游戏根目录/Evolved/...`、`游戏根目录/left4dead2/addons/...` 等结构。
4. 通过 Steam 正常启动游戏，按 **F8**。页面提示 BAT 启动可能使自带加载方式失效；遇到此问题先改回 Steam 启动。作者另列出 [L4N](https://steamcommunity.com/sharedfiles/filedetails/?id=3558049615) 路线，但本次没有下载、安装该额外项目。
5. 保持工坊订阅以接收更新提示。更新前备份配置；不要把本研究目录当作已经安装好的游戏目录。

**当前 1.2.5 下载包没有 `L4D2EvolvedPatcher.exe` 或其他安装 EXE。** 部分旧页面缓存提到的入口补丁工具不在本包中，不应据此补装或修改游戏 EXE。

## 基本操作

| 按键 | 功能 |
|---|---|
| F8 | 总设置，修改功能开关与快捷键 |
| F7 | 角色模型选择 |
| F6 | 模型部件、材质、透明度 |
| F5 | 模组管理器、优先级、预设与下载 |
| F4 | 当前武器/物品模型选择 |
| P | 舞蹈选择，需要相应动作/音乐资源 |
| Alt | 第三人称自由观察 |

在 F5 调整模组或加载预设后，使用界面中的应用并刷新功能；部分资源仍需要换图或重启。模型切换仅影响本地，不会把本机模型传给其他玩家。

ADS 需要武器模型本身具备相应动画/Bodygroup；插件不凭空生成动画。作者说明完整机瞄依赖本地房主或兼容服务端；缺少支持时主要是本地视觉效果，不能据此认为服务器散布、弹药和命中判定都改变了。外部 ADS/爬梯实现与内置功能重复时，先关闭内置对应项。

舞蹈相关聊天命令沿用作者说明：`!d z d01` 生成指定舞蹈，`!cam` 使用配套镜头，`!sd` 停止；需要另外安装资源。

## 当前版本新增点：小地图与拆分功能

包内更新日志记载：1.2.3 加入默认开启的小地图导航；1.2.4 改善复杂地形导航；1.2.5 再优化导航与实时解算。相比页面主体介绍，这部分包内资料更具体。

`Evolved/config.sample` 有以下参考项，**原文均带 `#`，不是正在生效的配置行**：

| 配置键 | 样例值 | 含义/证据边界 |
|---|---|---|
| `NoHmdMinimapEnabled` | `true` | 小地图开关 |
| `NoHmdWorldNavigationEnabled` | `true` | 世界导航开关 |
| `NoHmdMinimapToggleKey` | `key:ctrl+m` | 参考快捷键 Ctrl+M，实际可由用户配置改变 |
| `NoHmdMinimapRadius` | `600` | 小地图范围参考值 |
| `NoHmdMinimapWidth` / `Height` | `0` / `0` | 具体 0 值解释需运行确认 |
| `NoHmdMinimapPosition` | 空 | 样例未给位置格式，不据此编造坐标 |
| `NoHmdMinimapSize` | `0.210937634 0.236111075` | 双值尺寸参考，单位/锚点尚未验证 |

优先在 F8 查找小地图与导航设置。DLL 静态字符串包含 `Evolved/config.txt`、`Evolved/config2.txt`、`NoHmdConfigMenuKey`、`NoHmdMinimapToggleKey`；说明存在相关配置入口，不证明具体解析或热更新时机。若要手工配置，先让程序生成真实配置、退出游戏并备份，再参照样例修改对应项。

1.2.5 更新日志还声明：256 骨骼、实时解算、第一人称身体和准星修正已拆分，可在 L4N 插件菜单控制；`-noevo` 启动参数关闭 Evo 核心、保留拆分功能。本次只核对到作者日志和插件文件布局，没有运行验证拆分后的加载条件或性能收益。

## 与本项目 C 的关系

- 本次没有合入 C，C 文件 SHA-256 仍为 `97fa1e054d0676042b9da149b421e645aad493160db98b7f04668a2503e463da`。
- 两个内置 VPK 与 C 仅有 `addoninfo.txt` 同名，没有发现同路径运行资源覆盖；该结论不覆盖 DLL 运行时行为。
- Evolved 自带动态准星、模型管理和渲染改动，与 C 同时使用时仍需游戏测试。希望保留 C 的准星时，先检查 F8 的动态准星/战斗反馈开关，避免两个实现同时绘制。
- 项目另有用户提供的 `独立版map更新/`。本次没有执行、修改或自动合并它，也没有证明其中独立小地图 DLL 与 Evolved 内置小地图可同时使用。初测建议一次只启用一种小地图实现，便于定位问题。
- DLL 的游戏加载方式不能靠塞进 C 的 VPK 代替，不能把“资源不重名”解释成完整兼容。

## 渲染、卸载与限制

- 作者说明普通 D3D9 可继续使用，帧生成需匹配的 DXVK、显卡与驱动，默认关闭。先确认基础功能，再逐项启用，避免一开始同时叠加渲染组件。
- 卸载 BAT 包含“保留设置”和“完整卸载”两种分支，以及 `/preview`、`/preview-full` 参数；完整卸载会递归删除 Evolved/模型相关数据目录，不是单纯删两个 DLL。
- 卸载逻辑还会检查游戏进程和旧 EXE 入口补丁。这里仅审阅原文，没有执行预览或实际卸载；使用前应先核对目标目录和备份范围。
- 本次完成下载、改后缀副本、解压、静态 PE/配置/资源核查；没有启动下载的程序、安装游戏插件、改启动参数、测试联机或验证任何性能/稳定性/反作弊结论。
